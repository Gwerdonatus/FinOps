How to connect each provider
Use these steps when onboarding a client or recording the demo.
Tip: Save → Test → Sync
Stripe
  1. Get your key from Stripe Dashboard → Developers → API keys
  2. Paste sk_test_... → Save key
  3. Click Test → then Sync
    4. {% if demo_mode %}
  4. For demo: click Generate 250 demo transactions
    5. {% endif %}
Shopify
  1. Shopify Admin → Apps → App and sales channel settings
  2. Create a Custom App
  3. Enable Admin API scopes → Install app
  4. Copy Admin API access token → Save → Test → Sync
Paystack
  1. Paystack Dashboard → Settings → API Keys & Webhooks
  2. Copy secret key (sk_test_ recommended for demo)
  3. Save → Test → Sync
Recommended demo flow
  1. Stripe → paste sk_test_... → Save key
  2. Stripe → click Test (status becomes Connected)
  3. Stripe → click Generate 250 demo transactions
  4. Go back to Dashboard → watch metrics and alerts populate
